# ANDRI ALL DOWNLOADER
```Website downloader video/foto/audio dari YouTube, TikTok, Instagram, Facebook, Pinterest, dan Threads tanpa watermark.```

# Tech Stack
Frontend: Next.js 14 App Router, TypeScript, TailwindCSS, Neumorphic UI Design
Backend: Next.js API Routes
Database: Turso SQLite + Drizzle ORM
State: Zustand (LocalStorage for History)
Downloader Engine: @distube/ytdl-core + VidsSave API Wrapper
